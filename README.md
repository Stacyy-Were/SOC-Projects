# SOC Projects

A collection of hands-on cybersecurity projects I'm building while developing my skills in **SOC analysis, networking, Linux, Python, SQL and cybersecurity fundamentals**.

These projects are designed to help me move from learning cybersecurity concepts to actually applying them.

## Goals

* Build practical cybersecurity skills through hands-on projects
* Improve my Python and Linux skills
* Practice SOC analyst workflows and security investigation
* Understand networking and common attack techniques
* Build projects that demonstrate what I can actually do

## Projects

| Project                         | Description                                                           | Skills                              |
| ------------------------------- | --------------------------------------------------------------------- | ----------------------------------- |
| **Log Analyzer**             | Analyzes authentication logs and identifies suspicious login activity | Python, logs, SOC analysis          |
| **Brute-Force Detector**     | Detects possible brute-force attacks from authentication logs         | Python, authentication, detection   |
| **Linux Security Auditor**   | Checks a Linux system for common security issues                      | Linux, Bash, Python                 |
| **File Integrity Monitor**   | Detects unauthorized changes to monitored files                       | Python, hashing, file integrity     |
| **Phishing URL Analyzer**    | Checks URLs for common indicators of phishing                         | Python, web security                |
| **Network Traffic Analyzer** | Analyzes network traffic for potentially suspicious activity          | Python, networking, packet analysis |

> Projects will be added as I learn and build them.

## Learning Approach

I am building these projects incrementally rather than following completed solutions.

For each project, I aim to document:

1. What problem the project solves
2. The cybersecurity concept behind it
3. How the program works
4. What I learned
5. Challenges and troubleshooting
6. Future improvements

The goal is not just to have working code, but to understand **why it works and how the underlying security concept applies in a real environment**.

## Disclaimer

These projects are created for **educational purposes and authorized testing only**.

Any security testing should only be performed against systems, networks, or applications where I have explicit permission to test.
